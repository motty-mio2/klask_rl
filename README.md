# Klask MuJoCo Simulation & Reinforcement Learning

MuJoCo 物理エンジンを用いた卓上ボードゲーム「Klask (クラスク)」のシミュレータ環境、および強化学習 (Stable-Baselines3) によるエージェント学習プロジェクトです。

---

## 📐 エージェントの座標系 (Coordinate System)

強化学習モデル (AI) が扱う観測値 (Observation) と行動値 (Action) は、**テーブル中心を原点 `[0.0, 0.0]` とした正規化座標系**に基づいています。

### 1. 座標範囲と方向 (プレイヤー視点)

どちらのプレイヤーから見ても、常に手前側が負、奥側が正、左端が負、右端が正の対称空間として表現されます。

| 軸 | 方向 | `-1.0` (最小値) | `0.0` (中央値) | `+1.0` (最大値) |
| :---: | :--- | :--- | :--- | :--- |
| **X軸** | 左右方向 | **左端** (Left) | **中央** (Center) | **右端** (Right) |
| **Y軸** | 前後方向 | **自陣手前** (Ego Wall) | **中央** (Half-line) | **相手陣地奥** (Opponent Wall) |

```text
               [相手陣地 (Opponent Half)]
                     Y = +1.0 (奥端)
                           |
      X = -1.0 (左端) ----- [0,0] ----- X = +1.0 (右端)  <-- (ハーフライン)
                           |
                     Y = -1.0 (手前)
                 [自陣 (Player Half)]
```

---

### 2. 観測空間 (Observation Space) の正規化

1フレームあたりの状態値は、テーブルの実寸（左右幅 `0.16m`、前後長 `0.21m`）を基準に正規化されます。
さらに、履歴スタック数（`config.NUM_HISTORY_FRAMES` / デフォルト: 3）を掛け合わせた次元数（デフォルト: `12` 次元）がインプットになります。

* **パックのX座標**: `(実寸X座標) / 0.16` ➔ `[-1.0, 1.0]`
* **パックのY座標**: `(実寸Y座標) / 0.21` ➔ `[-1.0, 1.0]`
* **自ストライカーのX座標**: `(実寸X座標) / 0.16` ➔ `[-1.0, 1.0]`
* **自ストライカーのY座標**: `(実寸Y座標) / 0.21` ➔ `[-1.0, 1.0]`

> [!NOTE]
> **点対称の保証**:
> 相手プレイヤー (P2) 用の観測値を取得する際は、X・Y座標ともに自動的に `-1` が掛け算（180度反転）されてエージェントに入力されます。これにより、1つの同一ポリシーモデルだけで「先手・後手」両方の役割を制御可能です。

---

### 3. 行動空間 (Action Space) のマッピング

エージェントが出力する行動 `[Action_X, Action_Y]` (`[-1.0, 1.0]` の範囲) は、ストライカーの可動範囲に応じて物理位置へマッピングされます。

* **`Action_X` (左右移動)**:
  * `-1.0` ➔ 自身の可動限界の**左端**へ移動
  * `0.0` ➔ 自身の初期位置の**中央**を維持
  * `1.0` ➔ 自身の可動限界の**右端**へ移動
* **`Action_Y` (前後移動)**:
  * `-1.0` ➔ 自陣の最も**手前側 (壁際)** へ後退
  * `0.0` ➔ 自身の初期位置 (Y=-0.105m) を維持
  * `1.0` ➔ 物理的に移動可能な限界である**ハーフライン際**へ前進

## 🚀 実行・操作方法 (How to Run)

仮想環境（`.venv`）を構築した上で実行します。

### 1. エージェントの学習
セルフプレイとドメインランダマイゼーションを用いた強化学習（200万ステップ）を開始します。
```bash
uv run python3 src/klask_rl/train.py
```

### 2. 学習済みエージェントの可視化対戦 (デモ)
学習されたモデル同士（セルフプレイ）の3Dシミュレーション描画を起動します。
```bash
# デフォルトモデル (models/klask_ppo_model.zip) のロード
uv run python3 src/klask_rl/enjoy.py

# 特定のチェックポイントを指定してロード
uv run python3 src/klask_rl/enjoy.py --model models/checkpoints/klask_ppo_model_1000000_steps
```

### 3. 設定の変更
[src/klask_rl/config.py](file:///Users/user/Projects/klask/klask_mujoco/src/klask_rl/config.py) を書き換えることで、以下の制約を変更可能です。
* `INFERENCE_HZ`: 推論周期（30Hzなど）
* `MOTOR_MAX_VELOCITY` / `MOTOR_MAX_ACCEL`: モータスペック制限
* `NUM_HISTORY_FRAMES`: 観測する過去履歴の枚数
* `ENABLE_DR`: ドメインランダマイゼーションの有効/無効
* `PENALTY_PUCK_IN_OWN_HALF`: 自陣にボールがある時の放置ペナルティ
